# 豆瓣公开页面访问（无账号通道）

决策日期：2026-11-06。适用于 `dev` 渠道；本文件记录访问边界，避免后续把它误读成"未授权的抓取器"或"已获得豆瓣许可"。

## 决策

产品所有者确认：本应用是个人使用的观影工具，不转售、不再分发豆瓣数据，也不使用豆瓣原生版权剧集或图片资源。据此：

- 匿名读取豆瓣公开列表页（`/top250`、`/j/new_search_subjects`、`/j/search_subjects`、`/doulist/<id>/`），不再回避 `/j/` 路径。
- 不携带账号 Cookie、不代填密码、不做代理轮换、不解决验证码。请求使用固定的浏览器 UA 与 `Referer: movie.douban.com`，仅用于页面兼容；这不代表已获授权，也不用于绕过登录或验证码。
- 公开通道默认可用。这是产品所有者对个人使用范围的判断；本仓库不主张任何豆瓣许可或豁免，是否需要授权由使用者自行判断，该通道可随时撤下。BFF 的授权声明只约束其自有采集路径，不再是客户端的前置条件。
- 仍不把公开页面内容打包进 APK，不对外提供数据导出或共享接口。

## 用户入口

- 搜索页的「豆瓣 ≥ 8」与「豆瓣 TOP250」不再依赖 BFF：没有配置元数据服务时，客户端直接读取公开页面。
- 「豆瓣」模式下出现一行策展标签（热门、悬疑、科幻、动画、国产剧、美剧）；选中即加载该标签的公开列表，再次点击取消。
- 榜单条目显示 `TOP n` 角标；评分带「豆瓣」来源与抓取时间/陈旧标记，个人星级永远不会被写成社区评分。
- 原生 TV 的筛选行通过同一 `search.filter` 协议传递 `tag`，三个界面共用同一份数据语义。

## 匿名能拿到什么

| 内容 | 来源 | 说明 |
|---|---|---|
| Top 250（电影） | `/top250` HTML | 名次、标题、评分、海报 URL |
| 标签/类型浏览（电影与剧集） | `/j/new_search_subjects` JSON | 标签、排序、分页起点 |
| 热门（电影与剧集） | `/j/search_subjects` JSON | 单页 40 条 |
| 豆列 | `/doulist/<id>/` HTML | 单页；不做无限翻页 |

匿名**拿不到**条目详情（简介、演职员、剧照）与任意条目的社区评分：详情页会跳转到安全验证。这些只能由用户自己的登录会话读取，或由其它有授权的元数据源提供。UI 不得把匿名列表字段描述成"完整豆瓣信息"。

## 请求约束

常量位于 `data/douban/public/DoubanPublicGate.kt`：

- 相邻请求至少 3 秒，附加 0–900 毫秒抖动。
- 10 分钟窗口最多 20 次；超出后返回可见的可重试时间，而不是静默等待。
- 429 尊重 `Retry-After`；401/403/418 与验证页进入持久熔断；其余 4xx 按上游错误处理并冷却 60 秒；5xx 同样冷却 60 秒。

## 与 robots.txt 的关系

2026-11-04 的探测记录 `/j/` 被 `robots.txt` disallow。2026-11-06 的决定是仍以匿名、低频、单并发方式读取这些公开列表页。这是产品所有者的个人使用判断，不构成许可或合规结论；若权利人要求停止，应直接撤下该通道。
- 单次请求 connect 5s / read 8s / call 12s；超过 5 秒的门禁等待会以倒计时形式交给 UI。
- 门禁状态写入 `noBackupFilesDir/douban-public-gate.v1`，重启后仍然有效；用户显式断开或清理缓存时才重置。
- 同一时刻只允许一个匿名请求在飞；相同缓存键的并发调用在拿到锁后复用缓存。

## 缓存与新鲜度

- 结果缓存 7 天，最多保留 30 天的陈旧副本；网络失败时使用陈旧副本并明确标注。
- 页面只导出海报 URL，不打包图片；加载失败就退化为无图，不引入图片代理。
- 榜单快照 ID 以 UTC 日为单位稳定，同一轮分页不会被误判为"快照变化"；跨 UTC 零点的一轮分页会重新开始。

## 渠道边界

公开通道源码位于 `app/src/main/java/dev/cinematv/data/douban/public/`，仍落在 `cinematvChannel=stable` 的源码拒绝目录内。也就是说：

- 当前 `dev` 线可产出带豆瓣功能的安装包。
- `stable` 线在源码层面拒绝豆瓣目录，不包含本功能。
- 如果未来要在 stable 提供公开榜单，需要把公开通道移出该目录，并同时解除 `MainActivity`、`CinemaViewModel`、设置页与 `LocalMediaLibrary` 中的账号引用，再单独评审；不能直接放宽构建闸门。

开发者诊断日志见 [DIAGNOSTICS.md](DIAGNOSTICS.md)。

## 验收边界

单元测试使用合成 HTML/JSON，不证明线上结构长期稳定；真实账号、实体电视验收另行记录。任何"榜单已同步""评分已获取"的表述都必须带上抓取时间与来源；缓存命中不得说成在线更新。
