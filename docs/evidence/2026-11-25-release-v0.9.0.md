## Release scope

The stable branch takes the accepted `dev-compose` payload and excludes the unaccepted
Douban personal-account experiment:

- `data/douban` (account service, vault, LAN server, HTML parser, transport, models) and
  `ui/douban` (login activity, account panel, developer options) are deleted; the Gradle
  channel guard and both candidate scripts still refuse those paths.
- The anonymous public-list channel moved to `data/doubanchart`, and the diagnostic log
  moved to `ui/diagnostics`. Neither carries account state.
- `org.jsoup`, `org.nanohttpd` and `com.google.zxing` were removed: only the deleted
  account module used them, and their resolution was the source of repeated Maven
  Central 429 failures in CI.
- `douban-account-safety.yml` was replaced by `diagnostics-safety.yml`, keeping the
  instrumented diagnostics lane on API 33 and API 26.
