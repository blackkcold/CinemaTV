# CinemaTV 0.9.0（Stable / code 16）

发布：2026-11-25 · tag [`v0.9.0`](https://github.com/blackkcold/CinemaTV/releases/tag/v0.9.0)

## 本版变化

- 电视界面改为原生 Jetpack Compose（`TvRootApp` 单一入口），Media3 原生播放；旧 Hybrid TV Web 层已删除，历史保留在 `archive/tv-web-5c24360`
- 玻璃材质走 `backdrop` + `ProductionGlassScene` + `cinemaGlassMaterial` + `ProductionGlassPolicy`：API26–30、弹窗与播放器覆盖层回落 Basic，不采样视频 Surface
- 匿名豆瓣公开榜单（TOP250、标签、评分）保留；个人账号、扫码登录、本机会话与片单导入不在 Stable 源码中，`data/douban` 与 `ui/douban` 仍被构建闸门拒绝
- 诊断日志从账号面板拆出：设置 → 开发者选项 → 诊断日志，默认关闭、不上传、可导出本地 zip
- 移除 `jsoup` / `nanohttpd` / `zxing`——只有已删除的账号模块使用，源码零引用

## 已知限制

- 本版**没有**实体电视 T-gate，也没有四小时连续播放、HDR/解码器覆盖、热与内存压力或真机帧率结论。T-gate 现为开发者可选项，不再阻断发版；没做就不宣称。
- `tv-smoke` 完整设备矩阵（含 `tvNative` 生产入口）未在本版发布流程中运行；E-gate 与模拟器结果不构成实体电视认证。
- 未验证真实豆瓣账号登录与片单导入（相关功能不在本版源码中）。
