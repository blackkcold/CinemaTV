## Changes

- Removes the retired TV Web experiment and hybrid Android host: `frontend/tv-web/`,
  `app/src/main/java/dev/cinematv/hybrid/`, `scripts/hybrid/`, hybrid tests, the
  `app/tv-web.gradle` wiring and the `androidx.webkit` dependency. The original is
  recoverable from `archive/tv-web-5c24360`; it is not re-created on the mainline.
- Keeps the native Compose TV presentation and the independent phone UI. The native
  library-review dialog remains; the hybrid-only review route and root parameters are
  removed.
- Adds the G4 post-delete evidence and the G3.4 owner waiver. The owner explicitly
  waived the physical short smoke; emulator evidence is not physical acceptance.
- Repairs the glass-performance lane: the `glass-controls` cycle now returns to Home
  hero before measurement (12 keys / 24 measured windows), and the analyzer accepts the
  current schema 3 compact receipts. The full 9/9 E-gate baseline is recorded in
  `docs/evidence/2026-11-25-g6-glass-baseline.md`. BLUR was more expensive than FULL at
  p95 on that AVD; no material policy was degraded.
- Adds same-visual list/prefetch improvements: cached browse/history projections,
  one stable artwork list, shared backdrop decode dimensions and hoisted navigation
  entries. No focus, Back, favorites, source switching or playback rule changed.
- Keeps the 2A progress-write policy and 2B targeted library progress snapshot, the
  identity caching/hex/IO changes, and the native E-gate/QA hardening from the prior
  batch.

## Validation

- Full host build/test/lint, backend `tv-bff` and Python gate suites passed on the
  release source; exact commands and hashes are in the release provenance.
- Production-entry focus acceptance: `tier-direct`, policy/actual FULL, 5/6 paired,
  analyzer valid.
- `NativePlaybackSessionTest` includes a 3 s clock-progression assertion after the
  fixture HTTP server gained RFC 7233 byte ranges.
- Ten-minute real-VOD playback was 608.1 s with position +600.0 s, 14,401 rendered
  frames, 0 dropped and no playback error, on the local API34 TV AVD. This is E-gate
  evidence, not a TV/FPS claim.
- Glass E-gate: nine valid `glass-controls` trials, `completeComparison=true`; see the
  G6 receipt for the tier curve.

## Known limits

- No physical G3.4 short smoke (owner waiver); no physical G6.4 T-gate, two-device
  thermal run, four-hour playback, HDR/codec breadth or hardware certification.
- The full CI phone/tv1080/tv4k/API26/29/31/33/36 matrix and the no-Node Android guard
  must pass on the exact release source; the local host has only the API34 TV image.
- Golden recapture/review and real compressed artwork remain pending.
- The signed APK, certificate verification, same-signature upgrade and update-feed
  acceptance are external-signer outputs. The unsigned candidate is **NOT FOR
  INSTALLATION**.
