# CinemaTV v0.4.0 Preview — Immersive UI

This release replaces the television presentation layer with a native cinematic
scene, compact floating navigation, responsive hero, media rails and center-focused
discovery. Movies, series, search, details, library, live guide and grouped settings
have distinct layouts. Existing SVG launcher branding and centered TV banner remain.

- TV focus and scroll state are kept per route, rail and title. Horizontal movement
  stays within its content row; offscreen returns and modal/player focus are tested.
- A landscape image is decoded and validated before it replaces the scene. Missing,
  ambiguous or invalid art uses original atmospheric fallback, never a stretched poster.
- Still-image glass sampling, reduced motion and conservative low-memory/API fallback
  are centralized. Enhanced AGSL highlights remain opt-in; video surfaces are never sampled.
- Playback uses a bounded floating controller with track/speed panels, real duration
  and episode progress, background pause and safe return behavior.
- Phone screens use five tabs, separate touch layouts, and fitted landscape playback
  while preserving the player and progress across rotation.
- Metadata caches are bounded; ambiguous same-title matches and missing requested years
  are rejected. No credentials or public content feeds are bundled.

The release workflow requires the **same commit** to pass Android build, Lint,
13 JVM tests, 7 BFF tests, phone instrumentation and 1080p/4K TV UI instrumentation,
including six reviewed image comparisons per TV viewport. Missing screenshots,
focus traces or frame samples fail publication.
The evidence ZIP contains screenshots, image comparison results, test reports and
informational emulator frame timings. The home PNG is also attached separately.
The screenshots use fictional titles and original vector artwork; the synthetic
H.264/AAC test clip is confined to the instrumentation APK.

**Debug-signed preview.** Physical TV/2GB-box playback compatibility, four-hour soak,
HDR/codec coverage, production signing and a signed upgrade path remain uncertified.
Emulator viewports and frame timings do not establish physical TV GPU performance
or optical-refraction fidelity. See Release Gate #1 and the release checklist.

Configure a self-hosted LibreTV instance and your authorized sources after installation.
A prior preview signed by a different CI debug key may require reinstalling; uninstalling
clears local data. The APK SHA-256 is included in `SHA256SUMS.txt`.
