## 本版变化

### 首页纵向焦点与默认内容

- 首页行间纵向移动改为显式遍历（`HomeFocusTraversal`），以稳定的语义区域键寻址，不再用展示文案做焦点键。
- 单次请求身份 + 导航/内容获取纪元守卫：过期请求不能把视口拉回，也不能在用户浏览时抢走焦点。
- 入口准备每次访问只执行一次；数据刷新只取消在飞请求，不再把用户拉回旧书签。
- 未声明类型的目录条目不默认成「电影」：仍可被搜索命中，但不进入首页货架。剧集在「发现」之前作为 hero 回退，并标注「类型未确认」。

### 搜索浏览态与筛选

- 三态展示：展开 / 浏览 / 筛选面板。浏览时浮动导航从组合树中移除，而不是变成透明。
- 结果首行 Up 到摘要行，摘要 Up 恢复导航，摘要 Down 回到最近结果；每条路径都受路由、代次与内容获取校验。
- 筛选收敛到一个单选面板，并引入显式评分模式，使「只带来源、无阈值」的历史过滤不会被显示成「全部」。
- 结果集代次与流式增量分离：新查询或筛选变更回顶部，流式到达不动位置。

### 跨源聚合与来源可达

- 新增更严格的搜索展示身份（`SearchGroupIdentity`）：未知季的剧集、未知类型的记录不跨源合并。
- 可信 ID 桶合并同一作品的译名；发布的 key 由证据推导，并提供确定的旧→新映射用于焦点迁移。
- 换源保留全部已确认候选（按版本 ID 可达），每个成员保留自己的剧集与进度身份。

### 复核中修复的持久化缺陷

`SearchHit.item` 原本同时承担「展示对象」与「点开后写入详情的权威记录」。中性搜索为不显示豆瓣评分，会从该记录上剥掉 `rating`/`ratingSource`/`doubanTopRank`/`ratingLicenseExpiresAt`，但按设计保留 `catalogAttribution`。`MediaSnapshotMerger` 因此把这条被剥空的记录当成权威目录更新，**永久擦除片库中已存的评分、TOP250 名次与评分许可到期时间**。

修复方式是把职责拆开：`item` 保持权威、任何展示规则都不再改写它；新增 `presentation` 只承载展示裁剪。UI 渲染读 `presentation`，打开与缓存仍走 `item`。并新增回归测试断言 `item` 原样返回、授权豆瓣筛选下展示与权威一致。
