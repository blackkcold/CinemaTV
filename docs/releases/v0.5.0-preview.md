# CinemaTV v0.5.0-preview · Personal Library

This is an Android TV and phone **preview**, not hardware-certified or production-signed.

## Client capabilities

- Room-backed Work / Season / Episode / Source records and measured, independent episode checkpoints. Legacy favorites, history and library states import transactionally; original preferences remain recoverable. Favorites no longer overwrite watching/watched status.
- Search displays local matches immediately, then adds optional catalog and LibreTV results. Title, aliases and actors are searchable; type, year, provider score and licensed Douban Top 250 filters never silently relax. Unknown types, conflicting years/IDs and ambiguous works remain separate.
- Recommendations use only the local library, favorites and viewing history. Dropped titles are excluded, completed titles are deprioritized, and personalized selections explain their reason. Cold start retains provider order. Browsing catalogs stay separate from personalized home ranking.
- Capacity-based basic/balanced/enhanced budgets limit artwork prefetch, playback buffering and cache size. These are conservative hints, not measured device performance or decoder certification.
- Source-resolved metadata and expired catalog records retain clear provenance. The optional licensed catalog ships no dataset. A separately gated, independently written Douban Top 250 acquisition adapter adds persistent throttling, shared refreshes, full pagination and explicit partial/stale/access status. It is disabled until applicable written permission is configured. TMDB and LibreTV fallbacks keep their own score labels.
- Local history, preferences and cached playback links are excluded from Android cloud backup and device transfer. Session credentials remain process-only as before.
- Approved V3 layered icons replace matching TV and phone navigation/action symbols using native vectors. Selection stays separate from D-pad focus, and light surfaces use a monochrome contrast fallback. Buttons use the approved V4 depth treatment; the original pre-rainbow A1 logo, static launcher icon/banner and brief, nonblocking in-app startup motion replace the earlier branding.

- TV ENHANCED on supported API 33+ hardware canvases can refract the settled scene still at the focused button's curved edge with subtle dispersion. The effect is opt-in and tightly bounded; reduced motion, low memory, missing artwork or a shader failure use the static depth fallback. Phone buttons use that static material and preserve native touch semantics. No video Surface or arbitrary UI framebuffer is sampled. See [the exact glass scope](../GLASS_V4.md).
- Offline Noto Sans Latin and Noto Sans CJK SC/TC/HK/JP/KR are bundled with original OFL notices. Region selection uses displayed-text language when supplied, then configured locales, with explicit SC fallback for untagged Han. Fonts load off the UI thread; first frame or failed assets keep usable system typography. The original brand outlines remain unchanged by typography. See [font provenance, size and limitations](../NOTO_TYPOGRAPHY.md).

## Verification and CI

Preview publication requires this exact commit to pass Android compilation, KAPT/Room generation, Lint, JVM/BFF tests, APK archive/signature validation, phone instrumentation (including real Room and adapter contract tests), and both TV UI viewports. Evidence is attached by the release workflow; do not infer a passed stage from this document alone.

Device QA now waits for the APK gate, cancels superseded same-ref runs, bounds compilation/instrumentation/ADB collection and retains partial diagnostic evidence. Single-device runs are for diagnosis; release still requires all required targets and unchanged screenshot thresholds. Minimum-API font/control compatibility is checked separately from the full phone navigation and two TV viewport scenarios.

Separate TV and phone tests on production base `449f358` successfully decoded a legally public Blender film through an isolated PeerTube-to-LibreTV-compatible adapter, including real search, pause/lifecycle, checkpoint and resume. This was a 240p MP4 and a compatibility adapter, not a deployed LibreTV server or a 4K decode test. See [exact runs, attribution and limits](../PUBLIC_MEDIA_ACCEPTANCE.md). Later icon, brand, button and typography changes are covered by the release candidate's own UI gate; the real-source runs are not relabeled as tests of this later commit.

## Remaining limits

- Physical 2GB box/Google TV/4K tests, four-hour soak, codec/HDR coverage, optical-glass GPU measurements, and private production signing remain mandatory before stable release.
- No written Douban permission or permitted live endpoint validation was available. The acquisition implementation is tested with synthetic fixtures, not live data, and remains inactive by default. Operators must verify rights and attribution requirements; a configuration declaration is not legal proof. See [the acquisition scope and activation gate](../DOUBAN_ACQUISITION.md).
- LibreTV responses without explicit season/type/episode names remain unknown or source-scoped. The app does not invent missing season mappings or transfer progress between unverified sources.
- The first Room schema imports SharedPreferences. Future Room versions must ship explicit tested migrations; destructive fallback is disabled.
- Debug CI keys can differ. Updating a differently signed APK may require uninstalling, which deletes local data; do not uninstall without understanding this risk.
