# CinemaTV v0.8.0-preview · Live Glass and Responsive TV Motion

Publication requires final-tree validation. The release run and immutable receipts, not this document, establish the result.

A debug-signed preview for Android TV and phones. Full live optics and plain blur follow the approved native component review. This is not a physical-TV performance certification or a privately signed stable build.

## Changes

- TV buttons and floating navigation use real Compose-scene glass. Full retains the accepted refraction, chromatic edge and softened highlight; Blur uses live ordinary blur without the optical lens. Foreground text is not recursively sampled.
- Conservative Basic/Blur/Full selection protects API26–30, low-memory devices, software windows, power saving, thermal conditions, startup and effect failures. AUTO never automatically enables Full. Explicit Full requires eligible API33+ conditions, while Blur requires API31+.
- Reduce Motion is independent of material selection. Focus, press and poster direction hints keep visible feedback without continuous decorative animation. Digital remote hints are not described as Siri-touch analog input.
- Cards keep the accepted springs, elevation, controlled parallax and image crop. Attached horizontal targets receive focus in the native key event; offscreen targets are prepared alongside smooth scrolling. New navigation, rapid reversal and data changes cancel stale pending focus.
- Focused rails preserve their existing visual padding when Reduced Motion changes, keeping the full scaled card caption within the parent viewport without shrinking the effect or changing the horizontal anchor.
- Deferred page restoration no longer overrides navigation or another control selected by the user. Saved bookmarks and real focus acquisition are tracked separately.
- Buttons retain stable native hit targets and single activation. Labels get predictable inset and constrained visual ellipsis while accessibility retains the full label.
- Selected glass filters retain a visible foreground marker independently of focus or background brightness. Narrow poster captions put the valid numeric rating together with its actual source first; complete metadata remains available to accessibility.
- Phone hero buttons use the same safe source boundary where supported. Other phone areas without a verified source remain Basic.

## Validation and limitations

The final release must link its exact candidate commit, source tree, APK SHA-256 and full phone/1080p/4K/API26 emulator acceptance. Focused component tests additionally cover API31 and API35, but an earlier focused run does not prove a later source tree passed.

Cloud-emulator measurements use real native remote events in a non-debuggable build, without recording. Window frame metrics measure app rendering work and cadence, not true physical presentation or remote-to-photon latency. Software GPU queues, empty activity windows and route/identity failures are reported, not hidden. No simple Full/Blur/Basic FPS ordering or hardware 60-fps guarantee is claimed from incomplete matrices.

Real Media3 SurfaceView pixels are not part of Compose layer recording. Player overlays deliberately use Basic; there is no fake blur of a movie still, recurring PixelCopy or CPU readback. Separate dialogs also use Basic unless they own a verified source.

Physical low-end TVs, vendor GPUs, 4K thermals, sustained sessions, codec/HDR breadth and private production signing remain stable-release gates. Reference implementations explain cost and design choices; their author-reported timings are not CinemaTV measurements.

## Provenance and installation

The optical engine is pinned to Apache-2.0 Kyant0/AndroidLiquidGlass commit 896a94a3ade1cc1a940b92365f942a34971fecda. Required license/notice and source modifications are retained and packaged. CinemaTV integration is MIT. pengchujin/aerial-tv was a visual/settings reference, not copied application implementation.

CI debug signing keys can differ. Do not uninstall an existing build solely to solve a signature mismatch without understanding that uninstall deletes local settings, library and history. Use the release APK/checksum and follow installation guidance; a benchmark-package APK is not the product update.
