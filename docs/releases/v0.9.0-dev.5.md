## 本版变化

### 双轨视觉主题

- 电视界面拆成两套视觉语言（Cinema / 画报 Poster），**共用同一个 `TvLayout` 与 `TvType`**，只改材质与色彩。因此切换主题只重绘，不重排。
- 新增 `TvVisual` 作为材质/色彩/焦点动效令牌的唯一来源，解析沿用既有的 `ProductionGlassProvider` 能力快照，不引第二套。
- 实测证据：同一路由在两种主题下播放尺寸相等而像素差异 41–49%，即「只重绘不重排」。
- **本版 AUTO 解析为 Cinema**。API 26–30 全部落在 Poster 触发区间，而那是要求支持的平台，没有 10 英尺证据前不改默认观感；Poster 只能手动选择，设置页只暴露两项。

### 真实字体字重

- CJK 由 `NotoSansCJK-Regular.ttc`（单 400 字面，600 靠合成）换成 `NotoSansCJK-VF.ttf.ttc`，提供真实的 400/500/600 字面；Latin 增加 `NotoSans-Medium.ttf`，使 500 不再回落 400。
- 字号表设置 `FontSynthesis.None`，缺失字重落到最近的真实字面，而不是合成笔画。
- `TvType` 的 display/hero/h2 由 `Bold(700)` 改为 `SemiBold`：700 不在 §5.4 字重表内，即使不改也会被静默匹配到 600；TV 令牌 7 处同步改为显式 `SemiBold`。
- 字形级实测 Δwidth 全为 0、Δheight −1 —— 无横向重排、无字号变化；放大并排确认新字面字腔开阔，旧合成粗体边缘发糊。

### 复核中修复的缺陷

- 字体地区懒加载曾把 38MB 字体集合的解析搬到 composition 主线程（改前全部在 `Dispatchers.IO`）；现改为 `suspend` + IO，未就绪时回退主地区家庭。
- 字体就绪契约原有 **7 份副本**散落在 5 个源集（含 `glassBenchmark`，其副本静默不产出有效样本）；现收束为 `CinemaNotoFonts.isReady` 单一定义，坏路径失败验证通过。
- `PosterMotionPolicy.scale()` 曾是死代码（生产无调用者、仅测试断言），现为唯一生产来源。
- `PosterScrimContrastTest` 曾测自己抄的一份 scrim 数字而非生产常量，改生产代码不会变红；已提取共用常量后重验可失败。
- 新增 `verifyPackagedFonts` 守卫，`finalizedBy` 挂到 `assembleDebug/Release/GlassBenchmark`：APK 内的字体集与 `noto-fonts.lock.json` 不符即构建失败。它存在的原因是一次 UP-TO-DATE 的陈旧 APK 一直携带被替换的 19MB 集合，使所有「新字体没问题」的结论实际测的是旧字体。

### tvNative 真机 lane 的两处既有缺陷

该 lane 自 2026-11-23 起持续失败，与本轮主题改动无关（在 base `f1e8181` 上同样失败），根因是两条写死了实现的判据：

- `MainActivityPathSmokeTest` 断言 `activity.isFinishing`。CI 设备日志的实际行为是 `ActivityTaskManager: moveTaskToBack` —— 平台把任务退到后台而非 `finish()`，`isFinishing` 永远为 false。`finish()` 与 `moveTaskToBack` 都是 HOME 退出的合法实现，契约应是「应用离开前台且不需要第二次按键」。已改为该契约，并把轮询移出 `rule.waitUntil`（应用后台化后 Compose 时钟不再空闲，用它轮询平台状态会抛 `ComposeNotIdleException`）。
- `qa-results-audit.py --require-tv` 只接受 `ro.build.characteristics` 含 `tv`。Google TV 系统镜像报 `characteristics = emulator`，其电视身份由 `android.hardware.type.television` 与 `android.software.leanback_only` 声明，因此这条唯一的真机 TV lane 在真实电视构建上永远无法通过。审计现接受两个来源，`run-device-qa.sh` 同时传 features。

## 已知限制

- **`tv4k` 在整轮 CI 中是既有 flaky**：同一 commit `1b7e193` 上一次失败（`45328665762`）、一次 21/21 全绿（`45332510107`）；本版合并 CI 红、单跑绿。超时点是 `RecommendationDashboardUiTest` 等待 `model.focused != null`，与主题改动无符号关联。
- **未验证**：物理电视 T-gate、真机 4K 观感、性能/FPS 采集、字体在各 API 版本上的实际渲染矩阵、手机端实机行为。
- `11-settings` 的端口遮罩已按实测输入重定位（同 60×36 尺寸，未扩大面积），不是布局变化。
- 编译、单元测试、lint 与模拟器 lane 都不构成 UX 或性能验收；模拟器结果不是物理电视认证。
- 签名、证书核验、同签名覆盖升级与更新 feed 验收均为外部签名机产出；未签名的候选包 **不可安装**。
- 本版推迟：字号收敛（§5.5）、h1 保持 32、片名 logo、首页热门仅做豆瓣第 2 层。
