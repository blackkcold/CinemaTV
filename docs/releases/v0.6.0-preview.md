# CinemaTV v0.6.0-preview · Reliable Local Library

A preview of the completed local-library follow-on work, not physical-device or stable-release certification. Debug-signed APK for Android phone and TV. Read the update/signature warning before replacing an installed build.

## Changes

- Catalog works try a bounded set of conservatively matched sources and supplied aliases. Cancellable requests, explicit provider failures, incomplete streams and configuration errors remain visible instead of becoming silent success.
- Browse and search can load additional metadata pages with provider/snapshot/permission continuity, deduplication and retryable partial results. Local personalized ranking stays on device.
- Per-episode progress follows supported source-specific identity through playlist reorder and signed-URL changes. Uncertain legacy positional checkpoints remain held, not assigned to another episode or deleted. Automatic cross-provider resume guessing is removed.
- Phone and TV detail pages navigate known works, seasons and individual sources. An explicit local editor can associate otherwise unmapped listings with evidence/conflict review, unknown seasons or specials, unlink and undo. Manual grouping never rewrites provider metadata or transfers checkpoints.
- Status removal and confirmed history clearing preserve independent favorites and statuses. Both touch and D-pad paths have dedicated tests.
- Automatic unlicensed `/api/douban` fallback is removed. Home uses configured metadata services or local records. Transport-labeled scores cannot masquerade as verified rating provenance. Live Douban acquisition remains disabled pending actual rights and a permitted endpoint.

## Verification scope

Publication requires the exact source tree to pass compilation, Lint, JVM/BFF/host tests and the full phone, TV1080, TV4K and API26 emulator matrix. The promotion receipt and run linked by the release workflow identify the tested checkout, source head and APK digest; a document alone is not proof of a pass. Identical-tree artifact promotion avoids rerunning those emulator jobs solely for a merge commit.

Official LibreTV v2.21.1 is tested as a separate, unmodified process. The controlled positive protocol run passed 27 checks, including JSON/NDJSON search, detail and attribution. The combined device gate adds direct repository→production Media3 playback of the unchanged Blender-hosted 240p H264/AAC film, rendered frames, clock advancement, pause/resume and checkpoint reload. The source is one static AppleCMS-shaped record, not a dynamic keyword/pagination/ID-filtering service. It does not establish home-backend compatibility, full-film decode, Android process-restart durability or every codec. See [official acceptance scope](../OFFICIAL_ANDROID_ACCEPTANCE.md).

## Important limits and update warning

- No home service or password manager was accessed. Private integration still requires separate permission after isolated testing.
- Physical low-memory/Google TV/4K testing, four-hour soak, codec/HDR breadth, measured GPU performance and private production signing remain open stable-release gates.
- Manual associations are local-only with one-level undo; no sync/import/export. Provider metadata without identity remains unknown until explicitly associated.
- Old positional progress remains preserved but may require choosing the episode and resume point again. No arbitrary token stripping or cross-source checkpoint copying is performed.
- CI debug signing keys can differ. Do not uninstall a previous build merely to resolve a signature mismatch without understanding that uninstall deletes local data.

The approved brand, bounded glass effects, performance tiers and offline regional Noto fonts continue from v0.5. See [installation](../INSTALL.md) and [stable-release checklist](../RELEASE_CHECKLIST.md).
